AppService Operator를 생성한다.
domain은 sample.io, group은 apps, version은 v1alpha1, kind는 AppService로 한다.
spec:
image: string
replicas: int32
status:
phase: string
readyReplicas: int32
message: string
Controller는 Deployment를 생성하고 갱신한다.
외부에서 Deployment의 replicas나 image가 변경되면 spec 기준으로 복구한다.
AppService 삭제 시 Deployment도 함께 삭제한다.
검증 명령은 make generate, make manifests, make test를 사용한다.
