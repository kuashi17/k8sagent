BatchApplication Operator를 생성한다.
domain은 sample.io, group은 batch, version은 v1alpha1, kind는 BatchApplication으로 한다.
spec:
image: string
command: []string
status:
phase: string
jobName: string
podName: string
message: string
Controller는 Job을 생성하고 관리한다.
Job이 생성한 Pod의 상태를 조회해 status에 반영한다.
Controller가 Pod를 직접 생성하거나 수정하거나 삭제하면 안 된다.
BatchApplication 삭제 시 Job은 함께 삭제한다.
검증 명령은 make generate, make manifests, make test를 사용한다.
